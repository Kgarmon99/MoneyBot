# Moneybot iOS App

A Swift-based iOS financial application with advanced ChatGPT integration, designed to provide intelligent financial assistance and analysis for Moneybotios2.

## Core Components

- Swift-native OpenAI integration
- iOS app architecture
- Real-time financial insights generation
- Comprehensive AI-powered financial analysis

## Setup Instructions

1. Open the project in Xcode by double-clicking the `Moneybot.xcodeproj` file.
2. Replace the placeholder "YOUR_OPENAI_API_KEY" in `Moneybot/Models/MoneybotService.swift` with your actual OpenAI API key.
3. Build and run the app on your preferred iOS simulator or device.

## Features

- Financial co-pilot powered by OpenAI's GPT-4o
- Interactive chat interface for financial advice
- Daily money challenges and goals
- Experience points and level progression system
- Streak tracking to maintain financial habits

## Requirements

- iOS 15.0 or later
- Xcode 13.0 or later
- Swift 5.5 or later
- An OpenAI API key with access to the GPT-4o model

## Note

This application requires a valid OpenAI API key to function properly. You can obtain an API key by signing up at [OpenAI's platform](https://platform.openai.com/).
